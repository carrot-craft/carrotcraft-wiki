## 🛒 株を売り買いする

`/kabu` で上場している国の一覧が開きます。国を選んで株数を決め、確認してから売買します。

- **いつでも売れて、いつでも買えます。** 相手のプレイヤーを待つ必要はありません（国ごとに売買用の「箱」があり、そこと取引します）
- **たくさん買うほど1株の値段は上がり、たくさん売るほど下がります。** 表示される額は目安で、実際の額は売買した時点で決まります
- 手数料は売買額の **1.5%** です
- 持っている株は `/kabu p`、売買の記録は `/kabu h` で見られます

<Callout type="warn">
  株は値下がりすることがあります。国が過疎になって欲しい人がいなくなれば、株価は下がります。**損をしても補てんはありません。** 余裕のある CC で遊んでください。
</Callout>

## 💰 配当

毎週 **土曜日 12:00** に、国の週の利益（**税収 − 維持費**）の一部が、持ち株に応じて株主へ配られます。

- 配る割合（配当率）は国王が **0〜100%** で決めます
- 国庫が維持費の3週分を下回るときは、その週の配当はお休みになります（国が潰れないように）
- 配当はオフラインでも届き、ゲームに入っているときは知らせが出ます

## 🏛️ 国を上場させる（国王向け）

<Steps>
  <Step>**申請する** — 国王が `/kabu apply` で申請します（上場料 **50,000 CC**）</Step>
  <Step>**運営の審査** — 条件を満たしているか、運営が確かめて承認します</Step>
  <Step>**公募を始める** — 国王が総株数・手放す割合（10〜60%）・1株の値段を決めて `/kabu ipo`。72時間、誰でも申し込めます</Step>
  <Step>**上場** — 申し込みが売り出す株数の半分に届けば上場し、売り買いが始まります。届かなければ中止になり、申し込んだ額は全額返ります</Step>
</Steps>

**上場の条件**

| 条件 | 内容 |
|------|------|
| 国ができてから | 30日以上 |
| 活動している住民 | 最近30日にログインした住民が10人以上 |
| 国王の在位 | 14日以上 |
| 処罰 | 国王に最近30日の処罰がない |
| 上場枠 | 全体で5国まで（運営が変えることがあります） |

公募で集まった CC は、およそ6割が国庫に入り、4割が売買用の箱に入ります。国庫に入った CC は返す必要がなく、国の発展に使えます。

## 👑 国王の決まり

国王は株を一番たくさん持っていて、国のことを一番よく知っています。株主が損をしないよう、国王には次の決まりがあります。

- **持ち株の30%以上は持ち続けます**
- **自分の株を売るときは、3日前までに告知します**（告知は全員に知らされ、7日で失効します）
- 国王が株を売って得た CC は **30日間凍結** されます
- 配当率を変えた前後 **24時間** は、国王は売買できません
- 国王をやめてから **90日間** は、元国王にも同じ決まりが続きます

## 🗳️ 株主総会

`/kabu soukai <国>` で、その国の株主総会の画面が開きます。

<Accordions>
  <Accordion title="増資（株を増やして国庫にお金を入れる）">
    国王は株を追加で発行して、国庫に CC を入れることができます（1年で総株数の30%まで）。
    株が増えるので、1株あたりの価値は薄まり、株価は下がります。

    - 国王が `/kabu issue <株数> <理由>` で提案すると、株主が **48時間** 投票できます（`/kabu vote <国> 賛成|反対`）
    - **反対が投じられた票の半分を超えたら否決**。無投票や同数なら可決します
    - 票の重さは締め切りのときの持ち株です。国王と元国王（90日）は投票できません
  </Accordion>
  <Accordion title="TOB（国を買い取る申し込み）">
    今の株価の **1.5倍以上** の値段で、国王を除く **株主全員の株を買い取る** 申し込みです。

    - 国の住人（首都の住人か、国の町の町長）が `/kabu tob <国> <何%>` で出します。代金は先に預かります
    - 国王が **承諾すると成立** し、全員の株が買い取られて、**申し込んだ人が新しい国王** になります
    - 国王が断る・申し込んだ人が取り下げる・72時間たつと、預けた代金は全額戻ります
  </Accordion>
  <Accordion title="大株主の特典">
    | 持ち株 | 特典 |
    |-------|------|
    | 1% 以上 | 国の財務（週ごとの税収・維持費）の詳細を見られる |
    | 5% 以上 | 主要株主として名前が載る |
    | 10% 以上で一番多い人 | 筆頭株主として名前が載る |
  </Accordion>
</Accordions>

## ⛔ 上場廃止

次のようなときは上場廃止になります。

- 国の住民が5人を下回り、警告から14日たっても戻らないとき
- 維持費の滞納（町の破産）が21日続き、警告から7日たっても解消しないとき
- 国王が申請したとき（30日後）・国が解散したとき・運営が判断したとき

廃止のときは、**売買用の箱の CC を株主へ持ち株に応じて配ります**（国王と元国王は受け取れません）。廃止の前には警告が出ます。

## 🌐 公式サイトで売り買いする

公式サイトの **株価** のページで、株価のグラフや最近の売買を見られます。**Discord でログイン** すると、サイトからも売り買いできます。

- サイトで売買すると、ゲームの中にも知らせが届きます。心当たりがなければ `/kabu webstop` で止めてください
- サイトで売買できるのは、サーバーに7日以上前から来ていて、10時間以上遊んでいる人です

## ⌨️ コマンド

| コマンド | 説明 |
|---------|------|
| `/kabu` | 上場している国の一覧・売買 |
| `/kabu p` | 自分の持ち株 |
| `/kabu h` | 売買の記録 |
| `/kabu soukai <国>` | 株主総会（増資・TOB・主要株主） |
| `/kabu vote <国> 賛成\|反対` | 増資に投票する |
| `/kabu tob <国> <何%>` | TOB を出す（例: 150） |
| `/kabu king` | 国王の画面（申請・公募・配当率・売却の告知） |
| `/kabu webstop` / `/kabu webstart` | サイトからの売買を止める・戻す |
