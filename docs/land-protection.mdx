<Callout type="info" title="このページの読み方">
**土地保護（CarrotGuard）** で、町の外の自分の土地を **範囲ごと** 守る方法をまとめています。`/guard` の画面だけで、広さを選んで作成・延長・管理まで全部できます。チェスト単体を守る[チェスト保護](/docs/bolt)や、町全体を守る[Towny](/docs/towny)とは別の仕組みです。
</Callout>

## 🛡 土地保護とは？

**選んだ範囲** を丸ごと保護し、他のプレイヤーによる破壊・設置・盗難などを防げる機能です。保護には2種類あります。

<Cards>
<Card title="個人保護" description="誰でも作れる自分だけの保護。7日ごとに延長（無料）が必要。初心者期間中は作るのも無料。" />
<Card title="街保護" description="町長・副町長が作る、町の外を守る保護。期限なし。メンバー追加や細かい設定ができます。" />
</Cards>

|  | 個人保護 | 街保護 |
|---|---|---|
| 作れる人 | 誰でも | 町長・副町長 |
| 数・広さ | 1人3個まで・1個 **64×64** まで | 町の合計で **住民数÷2 × 512ブロック²**（最低 **64×64** は作れる） |
| 費用 | 初心者期間（参加から14日）は **無料**、過ぎたら **作るときに1回だけ**（64×64でちょうど **10,000CC**。1ブロック²あたり約2.44CC） | 1ブロック²あたり約2.44CC（上限 **10,000CC**） |
| 期限 | **7日ごとに延長が必要**（延長は無料） | なし |
| メンバー追加・設定 | できない（守る内容は固定） | できる |

<Callout type="warn" title="他人の建築物を無断で保護しないこと">
他人の建築物・土地を、本人の許可なく自分の保護範囲に含める行為は **禁止** です。発覚した場合、当該保護は **強制解除** され、**処罰の対象** となります（利用規約 3.1）。
</Callout>

## ✏️ 作り方

<Steps>
<Step>
### `/guard` を開いて「広さを選んで作成」

守りたい場所の **真ん中に立って** `/guard` を開き、下の段の **「広さを選んで作成」** を押します。
</Step>
<Step>
### 広さを選ぶ

**16×16・32×32・48×48・64×64** のボタンか、幅・奥行の **＋−（1・8ずつ）** で広さを選びます（高さは全域が対象）。
**「外に出て枠を確かめる」** を押すと画面が閉じ、選んだ範囲の枠がパーティクルで見えます（もう一度 `/guard` で続きから）。
</Step>
<Step>
### 作成する

**「この範囲で作成画面へ」** → 確認画面で **種類・広さ・費用** を確かめて **「>> 作成する」** を押します。作れない時はボタンが灰色になり、理由が表示されます。

<Callout type="info" title="木のクワでも選べます">
好きな形で選びたい時は、木のクワを持って **左クリックで1点目・右クリックで2点目** を指定してから `/guard` を開くと、その範囲で作れます。
</Callout>

<Callout type="info" title="町長・副町長は種類を切り替えられます">
町長・副町長は、確認画面の真ん中のボタンで **個人保護 ⇔ 街保護** を切り替えて作成できます。
</Callout>
</Step>
</Steps>

## ⏰ 個人保護の延長（7日ごと）

個人保護は **7日ごとに延長** しないと、自動的に消えます（建物は残ります）。延長は **無料** で、いつでもできます。

- `/guard renew` … 自分の個人保護を **すべて** 延長
- `/guard` → 下の段の **「個人保護をまとめて延長」**（時計）
- `/guard` → 保護をクリック → **「延長する」**（時計）

延長すると、**押した時から7日後** が新しい期限になります（日数の積み増しはできません）。期限の2日前からは、ログイン時やプレイ中に「延長してください」とお知らせが届きます。留守のあいだに消えた場合は、次にログインした時にお知らせが届きます。

## 🛡 守られる内容

| 内容 | 個人保護 | 街保護（作った直後） |
|---|---|---|
| ブロックの破壊・設置 | メンバー以外は不可 | メンバー以外は不可 |
| チェストを開く・ドアなどの使用 | メンバー以外は不可 | メンバー以外は不可 |
| 動物への攻撃 | メンバー以外は不可 | メンバー以外は不可 |
| 火の延焼 | 止める | 止める |
| 爆発（TNT・クリーパーなど） | 止める（持ち主のTNTも爆発しません） | 止める |
| PvP・モンスターの湧き | サーバーの通常どおり | サーバーの通常どおり |

個人保護の守る内容は **変えられません**。街保護は次の「設定」で切り替えられます。

---

## ⚙️ 街保護の設定（トグル）

`/guard` → 街保護をクリック → **設定** から、その保護の中で以下を **ᴏɴ（止める）／ᴏꜰꜰ（許可）** で切り替えられます。

| 項目 | 効く相手 | ᴏɴ にすると |
|---|---|---|
| ブロックの破壊 | メンバー以外 | 壊せない |
| ブロックの設置 | メンバー以外 | 置けない |
| 使用・チェストを開く | メンバー以外 | 使えない／開けない |
| 動物への攻撃 | メンバー以外 | 攻撃できない |
| PvP | 範囲全体（メンバーも） | PvP ができない |
| モンスターの湧き | 範囲全体 | モンスターが湧かない |
| 火の延焼 | 範囲全体 | 火が燃え広がらない |
| 爆発（TNT・クリーパー等） | 範囲全体 | 爆発でブロックが壊れない |

## 👥 メンバーを追加する（街保護のみ）

街保護の管理画面 → **メンバー追加** から、その保護の中で建築・チェストなどが使える人を追加できます。

- **オンラインの人**：一覧から頭アイコンをクリックして追加
- **オフラインの人**：**名前で入力（金床）** から名前を入力して追加（未参加のプレイヤーも指定可）

街保護は、その町の **町長・副町長なら誰でも** 管理できます（作った本人でなくても、町長が交代しても管理できます）。

<Callout type="info" title="個人保護ではメンバーを追加できません">
個人保護は1人用の保護です。仲間と一緒に建築したい場合は、町を作って **街保護** を使ってください。
</Callout>

## 🚫 保護を作れない条件（作れない場所）

<Accordions>
<Accordion title="共通（個人保護・街保護とも）">
- 既存の保護や、**Towny の町の区画と重なる** 場所
- 保護の **端から150ブロック以内に町がある** 場所
- 他人の建築物・土地（無断保護は規約違反）
</Accordion>
<Accordion title="個人保護のとき">
- 個人保護の **個数上限（3個）** を超える
- **広さの上限（64×64）** を超える
- 初心者期間を過ぎていて、**所持金（CC）が不足** している
</Accordion>
<Accordion title="街保護のとき">
- **町長・副町長ではない**
- 町の合計保護面積が **上限（住民数÷2 × 512ブロック²。最低64×64）** を超える
- **所持金（CC）が不足** している
</Accordion>
</Accordions>

<Callout type="info" title="町は他人の保護の上に区画を取れません">
町が区画を広げるとき、**ほかの人の個人保護や、ほかの町の街保護と重なる区画は取れません**。自分の町の住民の個人保護・自分の町の街保護の上だけ取れます（取った場合、その保護は外れます）。
</Callout>

---

## 🗑 保護が削除される条件

- **個人保護の期限切れ**：7日ごとの延長をしなかった
- **町の区画と重なった**：自分の町が区画を取って重なった保護は自動撤去
- **自分で削除**：管理画面 → 保護を削除 → 確認画面で「削除する」
- **規約違反**：他人の建築物の無断保護など、違反が確認された保護は運営が強制削除

どの場合も、**建物はそのまま残ります**（保護が外れるだけです）。

<Callout type="info" title="荒らされても復旧できます">
保護が外れて荒らされた場合でも、**運営に報告すればロールバックで復元** できることがあります（[補填・ロールバック](/docs/rules#6-補填ロールバック)）。
</Callout>

## 📋 コマンド

| コマンド | 内容 |
|---|---|
| `/guard` | 保護メニュー（一覧・作成・延長・管理・境界の表示。画面だけで全部できます） |
| `/guard renew` | 自分の個人保護をすべて延長（無料） |
| `/guard tool` | 範囲選択（木のクワ）の使い方 |
| `/guard create` | 選択範囲から作成（画面を開かずに作成） |
| `/guard list` | 自分の保護の一覧（個人保護は残り日数つき） |
| `/guard border` | 近くの保護の境界をパーティクルで表示（もう一度で消す） |

管理者向けには `/guardadmin`（全部の保護の一覧の画面・移動・延長・設定・削除など）があります。操作はすべて記録されます。
