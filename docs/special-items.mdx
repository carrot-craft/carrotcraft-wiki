<Callout type="info" title="特殊アイテムとは？">
  使うと、品ごとに違う **演出と動き** が出るアイテムです。夏祭りの品と、ハロウィンの飾りがあります。**使っても無くならず**、待ち時間が終わればまた使えます。
</Callout>

<Callout type="warn" title="動きが出ない場所">
  自分が建てられない町の中や、保護された場所では、**演出だけ** が出て動きは出ません。敵や動物への動きも、その相手がそういう場所にいる時は出ません。
</Callout>

- 待ち時間は品ごとに **人** に付きます。持ち替えても続けては使えず、ログアウトしても残ります
- 動きが効くのは自分と、敵のMOB・決まった動物だけです。ほかのプレイヤー、飼っている動物、名前を付けたMOB、村人、ボスには効きません。かき氷の雪玉もプレイヤーには当たりません
- 食べ物を食べても満腹度は回復しません
- 資源サーバーでも使えます
- 特殊アイテムは堆肥箱に入れられません

## 🛒 特殊アイテムの店

<Steps>
  <Step>
    **`/market` を開く**

    マーケットの画面の「お店を選ぶ」を押し、「特殊アイテム」を選びます。
  </Step>
  <Step>
    **今週の品を押す**

    確認の画面で値段を確かめて買います。買ったCCは戻りません。
  </Step>
</Steps>

| 項目 | 内容 |
| --- | --- |
| 入れ替え | 毎週 **土曜18:00（日本時間）** に、上の品から **1品** がランダムに並びます |
| 値段 | ★5 200,000 CC・★4 100,000 CC・★3 50,000 CC・★2 30,000 CC・★1 10,000 CC |
| 買える数 | 1人1週に **1個** まで（同じ人の別のアカウントも合わせて数えます） |
| 払ったCC | どこにも入らず消えます |

***

## 🎟️ 投票のガチャから

投票ガチャと VoteParty のガチャから **特殊アイテムガチャキー** が出ることがあります。キーを持って右クリックで開くと、特殊アイテムが **必ず1つ** 出ます。
