<Callout type="info" title="進捗とは？">
  国家サーバーで遊んでいるうちに達成していく、CarrotCraft だけの目標です。全部で 80 個以上あり、いくつかは達成するまで中身が分からない隠し進捗です。
</Callout>

## 🏆 進捗の見方

Java 版は進捗の画面（`L` キー）で見られます。CarrotCraft の進捗は 5 つのタブに分かれています。

| タブ | 主な中身 |
| --- | --- |
| CarrotCraft | はじめての一歩・町や交流・その他 |
| ニンジンと料理 | ニンジン・料理・お酒・農業 |
| お金と商売 | お金・ショップ・オークション・圧縮職人 |
| 冒険と戦い | 採掘・木こり・戦闘・装備 |
| カジノ | カジノのゲーム |

達成するとチャットでお知らせが出ます。

## 🎖 称号

進捗の中には、達成すると**称号**がもらえる物があります（全 32 種類）。付けた称号は、チャットと TAB の名前の前に絵で出ます。

称号の枠の色には意味があります。

| 色 | 意味 |
| --- | --- |
| 赤 | サーバーで最初に達成した 1 人だけが持てる称号。2 人目からは、進捗は達成になりますが称号はもらえません |
| 金 | 誰でも持てる称号のうち、一番に取った人の枠。2 人目からは白になります |
| 白 | 誰でも持てる称号 |

赤や金になるのは、決まった一部の称号だけです（赤が 4 つ・金が 2 つ）。たとえば Killer は赤の称号です。それ以外の称号は、一番に取っても白になります。

もらった称号は自動では付きません。付けたい物を自分で選んでください。

## 🔧 称号の付け方

<Steps>
  <Step>
    `/uc menu` を開く
  </Step>
  <Step>
    下の段の「称号」を押す
  </Step>
  <Step>
    付けたい称号を押す（外す時は「外す」）
  </Step>
</Steps>

コマンドでも付け外しできます。

| コマンド | 説明 |
| --- | --- |
| `/ctitle list` | 持っている称号の一覧 |
| `/ctitle set <ID>` | 称号を付ける |
| `/ctitle clear` | 称号を外す |

<Callout type="warn" title="称号とバッジはどちらか 1 つ">
  名前の前に出せるのは、称号か[圧縮職人のバッジ](/docs/artisan)のどちらか 1 つです。国家では、称号を付けるとバッジが外れ、バッジを付けると称号が外れます。資源の TAB では、称号を付けている間はバッジの代わりに称号が出ます。
</Callout>

## 🎨 称号の絵を見るには

称号の絵はリソースパックに入っています。サーバーに入った時に出るリソースパックの確認で、受け取るを選んでください。一度受け取れば、サーバーを移っても読み込み直しはありません。

## ❓ よくある質問

<Accordions>
  <Accordion title="称号が四角に見える">
    リソースパックを受け取っていないと、称号の絵が四角に見えます。サーバーに入り直して、リソースパックの確認で受け取るを選んでください。
  </Accordion>
  <Accordion title="一番に取ったのに金や赤にならない">
    金や赤になるのは、決まった一部の称号だけです。ほかの称号は、一番に取っても白になります。赤の称号は最初の 1 人しか持てないので、ほかの人が先に達成していると、進捗は達成になっても称号はもらえません。
  </Accordion>
  <Accordion title="付けていた称号が外れた">
    圧縮職人のバッジを付けると、称号は外れます。称号とバッジは、どちらか 1 つしか付けられません。
  </Accordion>
  <Accordion title="進捗の画面にタブが出ない">
    サーバーに入り直すと出ます。
  </Accordion>
</Accordions>
